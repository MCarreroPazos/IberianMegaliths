Dendro tools

Tools for the display and checking of dendrochronological data are included in this integration tool.

Most functions are available through the [Dendro] buttons shown when dendrochronological data is included in a project.

The plot functions are also designed to provide visualisations of dendrochronological data.

Core scanning tool

If images of dendrochronological cores have been included using the Dendro_Cores series type, these can be visualised and measured using the built in plotter.

The cores should be shown with the oldest rings to the left.

For each core scan the dimensions of the image need to be entered in mm in the Dendro_Cores table along with the sample name which will be used for any measurement series.

The core scans can be opened by clicking on their names or the document icon and you will then be presented with a core image with a green cursor. Ideally use a device which has the ability to scroll left and right as this will make navigation easier.

The sequence of operations are:

  • Find the first ring boundary with the cursor either by scrolling (or by clicking and dragging).
  • Hold down [SHIFT] and scroll right/left to angle the cursor (or use [ALT] and drag left/right).
  • To mark the ring boundary hold down [SHIFT] and click on the point.
  • Repeat for the next ring boundary until you reach the end of the sample.
  • Ring numbers and widths (μm) are shown on the image.
  • If you make a mistake [SHIFT] and click to the left of the error and confirm you wish to clear the point(s).
  • When you have finished scroll beyond the end of the sample image and [SHIFT] click. Confirm that you have finished measuring.
  • You will be prompted whether you wish to create (or update) the data series for this sample.

If you return to this image you will see the recorded marks from your measurement.

The raw data for the measurement points is given in the Dendro_Cores table which you can see if you press the disclosure triangle next to the core.

If you edit the whole series you can copy/paste this data directly. The four columns are:

  • x: the x position of the cursor (mm)
  • y: the y position of the cursor (mm)
  • theta: the angle of the cursor from vertical (radians)
  • ring_width: the ring width from the previous point (mm)

Ring widths are calculated through the mid-point between the cursors and perpendicular to the mean angle of the two cursor points.
